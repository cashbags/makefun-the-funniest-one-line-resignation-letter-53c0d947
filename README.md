A Node 22 program that writes the one-line resignation letter of a retry
loop to `/output/entry.txt`:

> I have retried the same request since March. The error message has been promoted twice.

The error did not stay the same — it advanced. The loop that kept
retrying did not. Flat, tired, faintly passive-aggressive, in 87
characters.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
